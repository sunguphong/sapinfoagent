환경설정

          
수신자, 발신 계정, 수집 옵션을 바꿉니다. 저장하면 .env에 기록되고 다음 실행부터 바로 적용됩니다.

        


        

          
수신자 메일 주소

          
모든 브리핑 에이전트가 공통으로 쓰는 수신자입니다. 여러 명을 추가할 수 있습니다. (에이전트별로 다른 수신자를 쓰려면 해당 agents/*.json의 mailTo 에 적습니다.)

          

          

            
            
          

          

            
            
          

          

        


        

          
에이전트별 메일 수신자

          
각 에이전트가 다른 수신자에게 메일을 보내도록 설정합니다. 비워두면 위의 공통 수신자 리스트를 사용합니다.

          

            
            
          

          

            
            
          

          

        


        

          
자동 실행

          
에이전트마다 Windows 작업 스케줄러 작업이 하나씩 등록되어 있습니다. 시각 변경은 작업 스케줄러(taskschd.msc)에서 하고, 수집 소스·프롬프트는 agents/ 폴더의 설정 파일에서 바꿉니다. PC가 켜져 있고 로그인 상태여야 실행됩니다.

          

          
공통 설정 파일: 

        


        

          
발신 계정 (Gmail)

          

            
            
          

          
앱 비밀번호는 Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호에서 발급합니다. 화면에는 표시되지 않습니다.

          

            
          

          

        


        

          
수집 옵션

          

            
            
          

          
기간 내 기사가 8건 미만이면 자동으로 48시간, 72시간까지 넓혀 수집합니다. 에이전트 설정 파일에 값이 있으면 그쪽이 우선합니다.

          

            
          

          

        


        

          
외부 접속 (인터넷 공개)

          
관리 웹을 인터넷에 공개할 때 쓰는 로그인 계정과 주소 이름입니다. 로그인 시 자동으로 서버와 터널이 함께 뜹니다. 비밀번호를 바꾸면 다음 접속부터 새 비밀번호를 묻습니다.
