SAP Info Agent

매일 아침 SAP 뉴스를 수집하고 Claude가 한국어로 요약해 메일로 보내는 에이전트

관리 웹 열기

수동 실행, 실행 기록, 발송된 메일 보기, 수신자 변경은 관리 웹에서 합니다.

관리 웹으로 이동 →
https://sap-info-agent.loca.lt

처음 접속할 때

  1. 안내 페이지가 뜨면 "IP Address" 칸에 안내받은 IP 값을 입력하고 Continue를 누릅니다. 같은 브라우저에서는 다시 묻지 않습니다.
  2. 로그인 창에 관리자에게 받은 아이디와 비밀번호를 입력합니다.
IP 값과 로그인 정보는 이 페이지에 적지 않습니다. 관리자에게 문의하세요.
